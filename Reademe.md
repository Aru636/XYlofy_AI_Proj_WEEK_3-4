# Sales Forecasting Dashboard

## Overview

This project analyzes Superstore retail sales using Time Series Forecasting and Machine Learning.

## Features

- Sales Dashboard
- Forecasting (XGBoost)
- Anomaly Detection
- Demand Segmentation

## Technologies

- Jupyter Notebook / Google Colab
- Pandas & NumPy
- Statsmodels
- Prophet
- XGBoost
- Scikit-learn
- Matplotlib / Seaborn / Plotly
- Streamlit

## Project Structure

```
app.py
pages/
data/
models/
```

## Deployment

Run

```bash
streamlit run app.py
```
